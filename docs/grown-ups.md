# Grown-up guide

Everything a parent needs to run Toddler Smash. For building and installing the
desktop app, see [desktop.md](desktop.md).

## The grown-up menu

**Hold Escape for 3 seconds.** A dark panel appears and the game pauses behind
it. Hold Escape for 3 seconds again to hide it. A toddler mashing keys
essentially never holds one key that long, which is why this is the way in.

**On a phone or tablet:** put one finger on the top-left corner and one on
the bottom-right corner, and hold both for 3 seconds. Small hands can't span
the screen like that, so it's just as hard to hit by accident.

Every option in the menu is also a button you can tap. On a keyboard:

| Key | What it does |
| --- | --- |
| **1** | Smash game |
| **2** | Piano game |
| **3** | Drawing game |
| **D** | Daytime mood |
| **B** | Bedtime mood |
| **C** | Show or hide the corner buttons that let the child switch games |
| **F** | Fullscreen (browser only) |
| **Q** | Quit (desktop app only) |

The highlighted button shows what's currently selected. Your choices are
remembered the next time the game opens.

In the desktop app, the menu also shows whether the keyboard lock is working.

## Games

**Smash.** Every key or tap makes something: the letter or number pressed,
shapes that arc and bounce, ripples, or now and then a googly-eyed blob.

**Piano.** Ten rainbow keys across the bottom of the screen (five to eight on
a phone, so each key stays big enough for a small finger).

- The number row plays them in order: 1 is the leftmost key, 0 the rightmost.
- Letters play the key under their spot on the keyboard, so Q is low and P is
  high, and the letter floats up.
- A tap or click plays whichever key column it lands in, anywhere on screen.

**Drawing.** Drag a finger (or hold the mouse button and move) to paint a fat
line that slowly shifts through the rainbow and hums as it goes: higher up the
screen, higher the note. Several fingers draw at once. Keys stamp a sticker:
the letter or number pressed, or a shape for any other key. Old drawing fades
away over about half a minute, so the screen never fills up and there's
nothing to clear.

Every note is on the same five-note scale, so there are no wrong notes, and
mashing still sounds like music.

## Moods

A mood changes the look and sound of whichever game is running.

- **Daytime** (default): a light sky, clear colours, unhurried motion, no
  flashing.
- **Bedtime**: a navy night sky with stars and a moon, soft pastels, motion at
  half speed, fewer things on screen, and quiet, low, gentle notes.

The child can't change the mood; only the grown-up menu can, so Bedtime stays
Bedtime.

## Letting the child switch games

With the corner buttons on (the default), each game has its own round picture
button in the top-right corner: a star for Smash, a little piano for Piano,
and a crayon for Drawing. Tapping or clicking one switches games; the current
game's button is the bigger one. Games aren't inside each other, so every
game is always one tap away.

They only respond to taps and clicks, not keys, so mashing the keyboard won't
flip games back and forth. If they're switching too often, or you want them on
one game, press **C** in the grown-up menu to hide the buttons.

## Before you hand over the computer

- **Browser:** open the grown-up menu and choose Full screen (or press F). A
  browser can't block every shortcut; Cmd-Q or Ctrl-W can still close the tab. For
  real lockdown, use the desktop app.
- **Phone or tablet:** open the site and add it to your home screen (iPhone/
  iPad: Share → Add to Home Screen; Android: menu → Install app). Launched from
  the icon it runs full screen with no browser bar, and works offline after
  the first visit. Android Chrome can also go full screen from the menu's
  Full screen button. To stop the child leaving the app, use the phone's own
  lock: **Guided Access** on iPhone/iPad (Settings → Accessibility), or
  **App pinning** on Android (Settings → Security).
- **Laptop touchpads:** three- and four-finger swipes are handled by the
  operating system and no app can block them. Turn them off before playtime:
  - Windows: Settings → Bluetooth & devices → Touchpad → Three-finger
    gestures / Four-finger gestures → Swipes: Nothing.
  - Mac: System Settings → Trackpad → More Gestures → turn off Swipe between
    full-screen apps, Mission Control and App Exposé.
- **Volume:** the game is quiet by design, but set the computer's volume
  before you start. The desktop app blocks the volume keys.

## Getting the latest version

The game saves itself on your device so it works offline. The catch is that
after an update you may still see the old version once. If a new game or
change doesn't show up:

- **In a browser tab:** reload the page once or twice.
- **From a home-screen icon:** fully close the app (swipe it away), then open
  it again. It can take two launches.

To check which version you have, open the grown-up menu: the line at the
bottom lists the game keys (for example "Keys: 1–3 game"), and the Game row
shows every game that's installed.
